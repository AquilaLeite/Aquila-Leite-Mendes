# Memorial Aquila-Leite-Mendes

Uma página memorial em português, criada com uma identidade visual afetiva e acolhedora. O projeto usa cores suaves, cartões de lembranças, tipografia editorial e layout responsivo.

## Arquivos

- `index.html` — conteúdo e estrutura semântica da página.
- `style.css` — cores, tipografia, cartões, layout responsivo e acessibilidade.

## Como personalizar

1. Abra `index.html`.
2. Substitua os textos de demonstração pelos nomes, biografias, fotografias e homenagens desejadas.
3. Para adicionar uma fotografia a um cartão, inclua uma imagem própria no repositório e ajuste o HTML/CSS do cartão.
4. Confira os textos em celular e computador antes de publicar.

**Importante:** os cartões atuais são modelos de demonstração; eles não representam pessoas reais. Troque-os por conteúdo autorizado antes de divulgar o memorial. Ao publicar fotografias ou relatos, respeite a privacidade e os direitos de familiares e demais pessoas envolvidas.

## Publicar com GitHub Pages

1. Envie `index.html`, `style.css` e este `README.md` para a raiz do repositório `AquilaLeite/Aquila-Leite-Mendes`.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`; salve.
5. Aguarde a publicação e confira a URL indicada na própria página de configurações do Pages.

## Acessibilidade e compatibilidade

- Documento marcado como português do Brasil.
- Navegação semântica e link para pular diretamente ao conteúdo.
- Indicadores de foco visíveis para navegação por teclado.
- Layout adaptado para telas menores.
- Respeito à preferência de movimento reduzido.
- Google Fonts é usado como aprimoramento visual; fontes de sistema são alternativas.
